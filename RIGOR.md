## Notes

CrystalLLM is a faithful Crystal port of ruby_llm by Carmine Paolino. It mirrors
ruby_llm's public API and tracks its version numbers. The idea is the original
author's, not mine.

The port was led by an AI. I put effort into guiding it, and the code went
through many rounds of review and of security checks, all by an AI. I have not
read the source code, and no human has reviewed it.

The port is complete, and I update it to track the upstream ruby_llm project. I
maintain it with an AI. I use it in production myself, but I make no
recommendation either way.
